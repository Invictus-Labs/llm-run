# Security

Report potential vulnerabilities using this repository's GitHub **Security →
Report a vulnerability** flow. Please avoid posting credentials or private
source material in public issues. Include a minimal synthetic reproduction,
affected version, and expected versus observed behavior.

This project launches locally configured programs. It is not a sandbox or a
security boundary around those programs. Custom adapter configuration is trusted
executable configuration. The built-in CLIs retain their own authentication,
permissions, configuration, and storage behavior.

Version 0.1.x is an early release. Security fixes will be released in the latest
version; there is no long-term support branch yet.
